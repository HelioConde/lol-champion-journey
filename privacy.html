Como seus dados são usados

PT-BR

O LoL Champion Journey consulta dados públicos de League of Legends por Riot ID por meio do backend gamer compartilhado. A chave da Riot não é enviada ao navegador.

Buscas recentes, preferência de idioma, snapshots locais e diagnósticos técnicos básicos são armazenados no seu navegador via localStorage. Esses dados podem ser apagados limpando os dados do site no navegador.

Snapshots demonstrativos não são tratados como histórico real. O histórico server-side planejado será gerado pelo backend a partir de respostas da Riot, e não por dados enviados livremente pelo navegador.

No momento, slots de anúncio são apenas espaços reservados. Antes de anúncios reais serem ativados, consentimento e fornecedores serão documentados aqui quando exigido.

English

LoL Champion Journey queries public League of Legends data by Riot ID through the shared gamer backend. The Riot API key is never sent to the browser.

Recent searches, language preference, local snapshots and basic technical diagnostics are stored in your browser using localStorage. You can remove them by clearing this site's browser data.

Demo snapshots are never treated as real history. Planned server-side history will be produced by the backend from Riot responses rather than arbitrary browser-submitted data.

Ad placements are currently placeholders only. Before real ads are enabled, required consent and providers will be documented here.
